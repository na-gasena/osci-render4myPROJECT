# 絵→音 変換方式サーベイ

本ドキュメントは、2D/3D画像を音声信号に変換する各種方式をまとめたものです。osci-render に実装済みの方式と、広く知られた他の方式の両方を含みます。

---

## 方式1: パラメトリック・パス・トレーシング（ベクター方式）

**osci-renderのSVG/テキスト処理で使用。**

- ベクター図形（直線・ベジェ曲線）をパラメトリック関数 `f(t) → (x, y)` として表現
- `t` を時間に沿って進め、x→左ch、y→右ch としてオーディオ出力
- オシロスコープのXYモードで元の図形が復元される

**実装箇所:** `Source/svg/SvgParser.cpp` の `pathToShapes()` — `juce::Path::Iterator` でパス要素を走査し、各要素を `osci::Line` / `osci::QuadraticBezierCurve` / `osci::CubicBezierCurve` に変換。Y座標は `-y` として反転（SVGは下向き正、オシロスコープは上向き正）。

**特徴:** ベクター画像にのみ適用可能。曲線が少なければ非常に高品質。ラスター画像には使えない。

---

## 方式2: 確率的最近傍探索（ラスター画像のXY変換）

**osci-renderの `ImageParser` で実装されている "HILLIGOSS" アルゴリズム。** ラスター画像（PNG/JPG/GIF）を扱う方式。

### 原理

1. 画像をグレースケール化し、各ピクセルの輝度を取得
2. ランダムな位置から開始し、**螺旋状に最近傍の明るいピクセルを探索**
3. 見つけたピクセルの座標を `(x, y)` として出力（-1〜1に正規化）
4. 明るいピクセルほど訪問確率が高い（`pow(pixel, thresholdPow)` で確率を制御）
5. 定期的にランダムな位置にジャンプして、画像全体をカバー

**実装箇所:** `Source/img/ImageParser.cpp` の `getSample()` / `findNearestNeighbour()`

**特徴:** ラスター画像を「点描」的にXY信号に変換。ノイジーだが、輝度情報をある程度保持。結果はベクター方式ほどクリアではなく、確率的なためフレームごとに異なるパターンになる。

---

## 方式3: ラスタースキャン（走査線方式）

**osci-renderの `ImageParser` に代替アルゴリズムとして実装。**

### 原理

1. 左上から右方向にスキャンし、閾値より明るいピクセルに到達したらその `(scanX, scanY)` を出力
2. 明るい部分ではスキャン速度を落とし（`tanh` で制御）、暗い部分は素早くスキップ
3. 画面端に達したら次の行に移動（テレビの走査線と同様）

**実装箇所:** `Source/img/ImageParser.cpp` の `getSample()` 内、`else` ブロック

**特徴:** 方式2よりも規則的。昔のテレビ放送（ラスタースキャン方式）に近い。実質的にSSTVと同じ原理。

---

## 方式4: 3Dワイヤーフレーム + 中国人郵便配達人問題（オイラー路）

**osci-renderの `.obj` ファイル処理で使用。**

### 原理

1. 3Dメッシュの頂点と辺をパースし、ワイヤーフレーム（辺のみ）を抽出
2. グラフの連結成分を求め、各成分に対して**中国人郵便配達人問題** (Chinese Postman Problem) を解く
3. これにより、すべての辺を最小コストで通る閉路（一筆書きに近い経路）を得る
4. その経路に沿って頂点を `osci::Line` の列に変換
5. あとは方式1と同じく、各線分を `f(t) → (x, y)` でトレース

3D→2Dの投影は `PerspectiveEffect` で実施。

**実装箇所:** `Source/obj/WorldObject.cpp`, `Source/audio/PerspectiveEffect.h`

**特徴:** グラフ理論の最適化問題を使って、辺の重複走行を最小化。3Dオブジェクトをオシロスコープに描画するための非常に巧みな方式。

---

## 方式5: Blenderシーンのリアルタイムストリーミング

**osci-renderの `ObjectServer` + `LineArtParser` で実装。**

### 原理

1. Blenderのアドオンが3Dシーンをワイヤーフレーム化し、JSONまたはバイナリ(GPLA形式)でソケット経由で送信
2. osci-render側で受信し、行列変換（回転・平行移動）と透視投影を適用
3. 描画順序を最適化（最近傍法で次に描く辺を選択）
4. 結果の `osci::Line` 列をパラメトリック・トレーシングで音声化

**実装箇所:** `Source/gpla/LineArtParser.cpp`

**特徴:** リアルタイムの3Dアニメーションをオシロスコープで表示可能。

---

## 方式6: フーリエ級数（エピサイクル方式）

**osci-renderには未実装。** しかし有名な方式。

### 原理

1. 閉曲線を複素平面上のパス `z(t) = x(t) + i·y(t)` として表現
2. このパスを離散フーリエ変換(DFT)で周波数成分に分解：
   ```
   z(t) = Σ cₙ · e^(i·2π·n·t)
   ```
3. 各 `cₙ` は「半径 `|cₙ|`、角速度 `2πn`、初期位相 `arg(cₙ)`」の回転する円（エピサイクル）に対応
4. すべてのエピサイクルを重ね合わせると元の曲線が再現される
5. オーディオ化：各エピサイクルを正弦波として加算合成

具体的には:

```
x(t) = Σ |cₙ| · cos(2π·n·f₀·t + φₙ)
y(t) = Σ |cₙ| · sin(2π·n·f₀·t + φₙ)
```

ここで `f₀` は基本周波数。つまり **加算合成（Additive Synthesis）** として実装でき、各倍音の振幅と位相がフーリエ係数 `cₙ` から決まる。

**特徴:**
- 閉曲線に最適
- 項数（倍音数）を増やすほど精密な再現が可能
- 数学的にエレガント（3Blue1Brown のフーリエ級数動画で有名）
- 開いた曲線や複数のパスには拡張が必要
- 音色は倍音構造を持つため「楽音的」に聞こえやすい

## 方式7: スペクトログラム・エンコーディング

**osci-renderには未実装。** XYモードではなく、通常のスペクトログラム表示で「絵」を埋め込む方式。

### 原理

1. 画像の各列（x方向）を「ある時刻における周波数スペクトル」と解釈
2. 画像のY軸 → 周波数軸、X軸 → 時間軸、ピクセル輝度 → その周波数の振幅
3. 逆STFT（短時間フーリエ逆変換）でオーディオ信号を合成

```
audio(t) = Σ_f  amplitude(f, t) · sin(2π·f·t + random_phase)
```

**有名な実例:**
- **Aphex Twin** の楽曲 "Windowlicker" や "\[Equation\]" — スペクトログラムを見ると顔が浮かび上がる
- **Venetian Snares** — スペクトログラムに猫の画像が隠されている

**特徴:**
- XYモードではなくスペクトログラム表示が必要
- 聴感上はノイズ的（位相をランダムにするため）
- 解像度はFFTサイズとホップサイズに依存
- モノラル1chで実現可能（XY方式は2ch必要）

---

## 方式8: SSTV（Slow Scan Television）

アマチュア無線で使われる、画像を音声で伝送する方式。

### 原理

1. 画像をラスタースキャンし、各ピクセルの輝度を**周波数**に変換（1500Hz=黒、2300Hz=白など）
2. 各ピクセルに対応する周波数のトーンを一定時間出力
3. 同期信号（1200Hzパルス）で行の切り替えを通知

**特徴:**
- 周波数変調（FM）の一種
- 1枚の画像に数秒〜数分かかる
- 受信側で復元可能（実用的な伝送方式）
- オシロスコープのXYモードでは絵にならない（通常のオーディオスペクトル）

---

## 方式9: 空間充填曲線スキャン

### 原理

1. **ヒルベルト曲線** や **Z-order曲線** などの空間充填曲線に沿ってラスター画像をスキャン
2. 曲線上の各点で `(x, y)` をオーディオサンプルとして出力
3. 輝度が高いピクセルの領域では滞留時間を長くする（明るい部分が「濃く」描かれる）

**特徴:**
- 空間的な局所性が保たれる（近くのピクセルは曲線上でも近い）
- ラスタースキャン（方式3）よりも走査線が目立ちにくい
- osci-renderには未実装だが、Luaスクリプトで実装可能

---

## 方式10: エッジ検出 + ベクター化

### 原理

1. ラスター画像にエッジ検出（Canny、Sobelなど）を適用
2. 検出されたエッジをベクターパス（直線・曲線）に変換（ポトレース等）
3. 以降は方式1のパラメトリック・トレーシングで音声化

**特徴:**
- ラスター画像でもベクター的なクリアな描画が可能
- 前処理が重い
- エッジの連結性を保つための経路最適化が必要

## 分類

大きく分けると:

- **XYモード方式**: 2チャンネルの信号を生成し、オシロスコープのXYモードで「描画」。座標をそのまま電圧に変換。
- **スペクトル方式**: 1チャンネルの信号に画像情報を周波数領域でエンコード。スペクトログラム表示で「見える」。

フーリエ変換を使う方式（方式6, 7）はあるが、osci-renderのような「パラメトリック・トレーシング」とは根本的に異なるアプローチ。方式6は曲線をフーリエ係数に分解して加算合成する方法で、理論的に美しいが、SVGのような複数の開いたパスを扱うには拡張が必要。方式7はそもそもXYモードではなくスペクトログラムに画像を埋め込む方法で、用途が全く異なる。
